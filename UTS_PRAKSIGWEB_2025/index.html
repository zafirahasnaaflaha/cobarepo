UTS PRAKTIKUM SIGWEB

Praktikum SIGWEB merupakan salah satu mata kuliah pilihan yang ada di geodesi ugm.

Mata Kuliah ini membahas mengenai bagaimana pembuatan website khususnya uuntuk keperluan GIS. Minggu pertama perkuliahan kamu dikenalkan mengenai penggunaan bahasa pemograman dalam membangun Web yaitu HTML,CSS, dan JS. Pada minggu selanjutnya kami melakukan latihan untuk membuat web sederhana dengan beberapa syarat seperti menggunakan heading yang berbeda kemudian menggunakan warna pada tulisan dan menambahkan link website ke script html. Kami juga mempelajari pembuatan CV menggunakan web WIX. Minggu ke 4 kami mulai diperkenalkan untuk menggunakan GITHUB yang tujuannya agar pekerjaan yang kita buat dapat diakses secara umum. Minggu-minggu selanjutnya kami mulai belajar membuat peta dengan Leaflet dan mengkombinasikannya dengan berbagai plugin seperti menambahkan openstreetmap, menggunakan geoJSon dan menambahkan Bootstrapt.
